# نموذج دريفوس لاكتساب المهارات

https://en.wikipedia.org/wiki/Dreyfus_model_of_skill_acquisition

نموذج دريفوس لاكتساب المهارات هو نموذج لكيفية اكتساب المتعلمين للمهارات عبر التعليم الرسمي والممارسة، ويُستخدم في مجالي التعليم وبحوث العمليات.

يقترح النموذج أن الطالب يمر بخمس مراحل متمايزة:

* مبتدئ
* كفاءة
* إجادة
* خبرة
* إتقان
