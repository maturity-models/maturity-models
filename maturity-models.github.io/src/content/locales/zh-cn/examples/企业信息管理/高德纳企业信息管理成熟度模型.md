# 高德纳（Gartner）企业信息管理成熟度模型

参见 [The Gartner's EIM Program Maturity Model](https://image.slidesharecdn.com/chief-data-officer-forum-role-of-metadata-and-data-quality-in-data-analytics-feburary-2016-shared-ve-160217015631/95/iag-presentation-at-the-chief-data-officer-forum-sydney-8-638.jpg)

## 0 级：无意识
* 业务部门和 IT 部门不知道信息是个问题，而用户不信任数据。
* 由于信息管理不足，组织面临重大风险，例如合规失败、客户服务不佳和生产率低下。

## 1 级：有意识
* 对信息战略和数据治理的重要性有一定认识。
* 组织理解对通用标准、工具和模型的需求。
* 在人员、流程和技术上投入极少；缺乏业务赞助和参与。
* 已开始努力记录与不受控信息资产相关的风险。
* 对数据质量差以及关键主题领域的信息碎片化、不一致的认识正在增强。
* IT 部门通过纵向孤岛整合（数据仓库）寻求效率，使用数据建模师和数据库管理员。
* 商业智能（BI）继续生成不一致或冗余的报告。

## 2 级：被动
* 信息管理（IM）战略与路线图、治理和流程正在形成。
* 组织采取措施迈向跨部门共享，以实现运营效率。
* 正在投资提升某些领域的 IM 能力。
* 充分理解不将信息作为企业资产加以管理的风险。
* 正在形成关注信息、文件、电子邮件等保留期的指标，以应对已知的安全与合规风险。
* IM 政策和标准已发布，但遵守和合规程度仍然较低。
* 架构良好的数据仓库（DW）/商业智能（BI）框架/技术的基本要素正在形成。

## 3 级：主动
* 战略与路线图、治理和流程已就位，使主动的 IM 成为可能。
* 业务部门充分赞助和参与，推动全企业范围的举措。
* 组织为 IM 技术设定标准：分析、企业数据管理的独立架构，在业务层面统一的联邦式 DW/BI——信息即服务（信息服务层与面向服务的架构（SOA））。
* 完全遵守 IM 政策和标准。
* 运营风险降至最低：随着项目的实施，IM 嵌入软件开发生命周期（SDLC），由信息所有者和信息管理员组成的治理委员会帮助将信息作为资产进行管理。

## 4 级：受管理
* 业务和 IT 的高级管理层将信息学视为战略资产，接受并资助企业信息管理（EIM）计划，该计划针对关键利益相关方和需求，并与基于业务战略的优先事项保持一致。
* 一致且成熟的治理、政策、程序和 EIM 运营模式确保所有 IM 活动的协调。
* 识别最佳实践，EIM 团队确保这些实践在整个企业推广。
* 通过 DW/BI 仪表板和记分卡管理企业绩效。

## 5 级：有效
* 高级管理层将信息视为竞争优势，并利用它创造价值、提高效率。
* 企业数据作为战略资产在整个价值链中得到有效、合乎道德且高效的管理。
* EIM 小组协调全企业的所有信息工作。
* 组织努力使 IM 对业务和技术组织都更加透明，业务层面的数据所有者和管理员发挥积极作用。
* 组织已实现其 EIM 目标。
