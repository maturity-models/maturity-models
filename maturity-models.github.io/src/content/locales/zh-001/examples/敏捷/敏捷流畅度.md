# 敏捷流畅度

参见 [James Shore 和 Diana Larsen 的敏捷流畅度](http://martinfowler.com/articles/agileFluency.html)

<table>

一星团队创造业务价值

* 收益：对团队工作有更高的可见性；有能力调整方向。
* 投入：团队发展和工作流程设计。
* 核心指标：团队定期从业务价值的角度汇报进展。
* 透明度：管理层知道团队何时在构建错误的东西，或何时没有进展，并有能力进行积极干预。
* 对齐：团队协同工作，减少误解和交接延误。

两星团队按市场节奏交付

* 收益：缺陷少、生产率高。
* 投入：技术技能发展期间生产率下降。
* 核心指标：团队按市场节奏发布。
* 透明度：从概念到交付的周期短，使系统性缺陷尽早暴露。
* 对齐：高技术质量和频繁交付带来高士气和更高效的工作。

三星团队优化其价值

* 收益：交付价值更高，产品决策更好。
* 投入：耗费社会资本，将业务专长融入团队。
* 核心指标：团队提供具体的业务指标。
* 透明度：团队使用具体的业务指标汇报其成果，例如投资回报率（RoI）、人均净利润和客户满意度。
* 对齐：团队与其组织之间的相互信任带来快速、有效的协商，团队广泛的专业能力消除了交接并加快了决策。

四星团队为优化整个系统做出贡献

* 收益：与组织目标保持一致；产生协同效应。
* 投入：在建立组织文化、发明新实践方面付出巨大努力。
* 核心指标：团队汇报其行动如何影响整个组织。
* 透明度：团队在企业其他举措的背景下描述其工作，使各产品之间得以相互平衡。
* 对齐：团队与其他团队及组织的其他部分相互交流观点、背景和创新。
