# 社交媒体成熟度模型

[Google 表单自我评估链接](https://docs.google.com/forms/d/e/1FAIpQLSfOHozbFWpieTsF6FCJrG9WtzfqOJFG9GuQF8Jmbwd_BHeyKA/viewform)

<h2>1. 社交媒体的入门阶段</h2>

<b>行动：</b>

* 公司开始倾听和观察客户与竞争对手在社交媒体上的情绪和语气

<b>成功标志：</b>

* 以客户、委托方或合作伙伴偶尔的提及来衡量。

<b>要素：</b>

* 个别员工在公司未参与的情况下使用一些社交媒体
* 公司没有社交媒体政策或战略
* 公司没有持续监控社交媒体上的提及


<h2>2. 社交媒体的规划与试点阶段</h2>

<b>行动：</b>

* 公司或受聘机构制定可实现的战略并实施试点计划。
* 明确平台和社交媒体日历，包括增长优先事项。

<b>成功标志：</b>

* 以不断提高的认识以及召集合适的人员共同制定战略（包括平台、风险策略和期望成果）来衡量。
* 开始跟踪基本分析数据。

<b>要素：</b>

* 单个部门（公关、人力资源）使用社交媒体
* 对社交媒体战略的需求显而易见
* 没有应对社交媒体提及的固定程序


<h2>3. 社交媒体的以客户为导向阶段</h2>

<b>行动：</b>

* 公司的各项决策都考虑社交媒体程序，既通过明确界定的公司文化为决策提供信息，也增加价值和营销机会。

<b>成功标志：</b>

* 以获客和购买路径上的投资回报率（ROI）来衡量。
* 客户支持成本降低。
* 公司通过社交媒体被视为随时可及、准确且真实可信。
* 公司的联系变得可见并增加价值。

<b>要素：</b>

* 社交媒体用于明确的特定目的
* 社交媒体通过跨越并支持多个部门来支持公司内部文化
* 社交媒体是营销活动的组成部分
* 社交媒体通过表彰来支持个别员工
* 公司与客户、委托方或合作伙伴通过社交媒体对话
* 社交媒体政策明确陈述并为全公司所知
* 有应对社交媒体提及的固定程序


<h2>社交媒体的整合阶段</h2>

<b>行动：</b>

* 公司通过跨部门实施社交媒体战略，轻松地维护多个平台，涵盖不同的内容和语气。

<b>成功标志：</b>

* 以既定且被充分利用的公司文化来衡量，这种文化体现在公司各层面的互动中。
* 观察到特定于业务线的指标。
* 专业团队继续跨部门工作，推进社交媒体战略、行动和成果。
* 所有部门和公司成员都被纳入战略和责任，并乐于担任社交媒体角色。
* 公司被客户和合作伙伴公司视为解决方案的推动者。

<b>要素：</b>

* 合作网络的内部文化通过社交媒体得到体现和支持
* 个别员工为社交媒体战略做出贡献并增加价值
* 客户、委托方和合作伙伴开发并开展社交媒体协作活动，并自发地增加价值
* 持续开展协作活动的结构成为营销战略中的优先事项
* 公司内部文化与外部客户/委托方文化融为一体
* 公司独特的视角和方法得到巩固，并在内部和外部受到赞扬
