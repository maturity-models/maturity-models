<h2><a name="宏观能力">宏观能力</a></h2>

IT-CMF 是围绕四项宏观能力实现渐进式改进的蓝图：

* 像经营企业一样管理 IT
* 管理 IT 预算
* 管理 IT 能力
* 以业务价值为导向管理 IT

共有五个成熟度等级：

* 初始
* 基础
* 中级
* 高级
* 优化

<h2><a name="像经营企业一样管理-it">像经营企业一样管理 IT</a></h2>

1. 初始 - 不受管理

  * 没有 IT 战略

  * 没有已定义的 IT 流程

2. 基础 - 成本中心 - IT 是成本中心

  * 已有资产和成本中心系统

  * IT 完全专注于技术和流程

  * 一些 IT 流程已有文档记录

3. 中级 - 服务中心 - IT 以客户和服务为导向

  * 已有成本回收和成本核算系统

  * 实施服务交付和管理实践

4. 高级 - 投资中心 - IT 专注于服务和使用的卓越

  * IT 客户与供应商关系管理出色

  * 资金机制灵活

  * IT 使用动态资源分配

5. 优化 - 价值中心 - IT 是价值中心，并定期发布价值声明

  * IT 与业务价值高度一致

  * IT 组织使用平衡计分卡推动持续改进

  * IT 组织具有很强的创业精神


<h2><a name="管理-it-预算">管理 IT 预算</a></h2>

1. 初始 - 不受管理 - 财务绩效不稳定

  * IT 预算没有明确的负责人

  * IT 支出不可见且零散

  * IT 资金与长期业务价值不一致

2. 基础 - 可预测的财务绩效

  * 存在明确的 IT 预算

  * IT 对照定期的财务和支出计划跟踪绩效

  * 实际支出与计划支出之间的差异保持在规定的控制限度内

3. 中级 - 系统性成本削减 - 已有系统性成本削减流程

  * IT 单位成本每年呈趋势变化并降低

  * 已有动态基线 IT 预算方法

4. 高级 - 扩大资金来源 - IT 已吸引多种资金来源

  * 节省的成本被转移到战略投资或计入利润

  * IT 预算符合治理和 IT 使用原则

  * IT 预算与长期业务价值一致

5. 优化 - 预算放大 - 稳定的 IT 预算支持公司的增长需求

  * 预算分配在基于价值绩效的适当组合之间保持平衡

  * 积极管理 IT 强度，并与其他关键的企业支出类别进行比较

  * 预算由长期的组织和业务路线图驱动


<h2><a name="管理-it-能力">管理 IT 能力</a></h2>

1. 初始 - 不受管理 - 用户自行购买和维护 IT 系统

  * 没有正式的 IT 机构

  * IT 系统没有集成

2. 基础 - 公用事业或技术供应商

  * 对 IT 组织的尊重不断增加

  * 公司将 IT 纯粹视为成本中心

  * IT 是需要持续削减的成本

3. 中级 - 技术专家 - IT 在提供可靠的优质服务方面有成功记录

  * IT 组织被视为技术专业知识的来源

  * IT 提供可靠的公用事业式 IT 服务，并对绩效和成本进行基准比较

4. 高级 - 战略业务伙伴 - IT 领导层与业务领导层融为一体

  * IT 交付在特定业务领域提供价值的解决方案

  * IT 在目标领域提供关键的竞争能力

  * IT 领导者了解业务，并主动针对关键机遇和问题提出解决方案

5. 优化 - 战略核心竞争力 - IT 使信息和/或执行力优于竞争对手

  * 源源不断的解决方案带来竞争优势

  * IT 被公认为具有差异化优势的核心竞争力


<h2><a name="以业务价值为导向管理-it">以业务价值为导向管理 IT</a></h2>

1. 初始 - 不受管理 - 决策基于成本而非价值

  * 不了解也不衡量 IT 所提供的价值

  * 总拥有成本肆意攀升

2. 基础 - 总拥有成本 - IT 计算主要资产的总拥有成本

  * IT 定期跟踪总拥有成本，以确保持续降低成本

  * IT 计算整个生命周期的总拥有成本

3. 中级 - 简单的投资回报率与商业论证纪律

  * 有纪律地使用和评审商业论证

  * IT 已有投资治理或业务价值计划

  * IT 对商业论证使用多指标分析，以确定质量最佳的投资

4. 高级 - 组合与期权管理

  * IT 有主动的组合管理计划

  * IT 使用期权管理方法来挑选和管理具有投机性的 IT 投资

  * IT 将风险和风险价值作为商业论证的关键组成部分来权衡

5. 优化 - 优化的投资回报

  * IT 进行复杂的投资和组合分析，以优化投资和支出

  * IT 赋能投资的回报等于或高于公司其他类型投资的回报

  * 历史数据使得能够准确预测未来投资的价值
