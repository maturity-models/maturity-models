# 工程阶梯

https://github.com/jorgef/engineeringladders

技术：对技术栈和工具的了解

* 采纳：积极学习并采纳团队确定的技术和工具
* 专精：成为一项或多项技术的首选专家，并主动学习新技术
* 布道：研究、创建概念验证并向团队引入新技术
* 精通：对系统的整个技术栈有非常深入的了解
* 创造：设计并创造被内部或外部团队广泛使用的新技术

系统：对系统的所有权程度

* 增强：成功推送新功能和缺陷修复，以改进和扩展系统
* 设计：设计并实现中大型功能，同时减少系统的技术债务
* 拥有：负责系统的生产运行和监控，并了解其服务等级协议（SLA）
* 演进：演进架构以支持未来需求，并定义其 SLA
* 领导：领导系统的技术卓越，并制定缓解故障的计划

人员：与队友的关系

* 学习：快速向他人学习，并在需要时始终挺身而出
* 支持：主动支持其他团队成员并帮助他们取得成功
* 指导：指导他人以加速其职业成长，并鼓励他们参与
* 协调：协调团队成员，提供有效反馈并主持讨论
* 管理：管理团队成员的职业发展、期望、绩效和幸福感

流程：对开发流程的参与程度

* 遵循：遵循团队流程，持续向生产环境交付功能
* 执行：推行团队流程，确保每个人都理解其益处和权衡
* 挑战：挑战团队流程，寻找改进它们的方法
* 调整：调整团队流程，倾听反馈并引导团队完成变革
* 定义：为团队的成熟度水平定义合适的流程，平衡敏捷与纪律

影响力：该职位的影响范围

* 子系统：对一个或多个子系统产生影响
* 团队：对整个团队产生影响，而不仅仅是其中的特定部分
* 多个团队：不仅对自己的团队，也对其他团队产生影响
* 公司：对整个技术组织产生影响
* 社区：对技术社区产生影响
