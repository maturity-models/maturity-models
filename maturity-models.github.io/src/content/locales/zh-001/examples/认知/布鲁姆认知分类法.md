# 布鲁姆认知领域分类法

https://en.wikipedia.org/wiki/Bloom%27s_taxonomy

https://cft.vanderbilt.edu/guides-sub-pages/blooms-taxonomy/

**记忆** - 回忆事实和基本概念。定义、复述、列举、记住、重复、陈述。

**理解** - 解释想法或概念。分类、描述、讨论、解释、识别、定位、认出、报告、选择、翻译。

**应用** - 在新情境中使用信息。执行、实施、解决、使用、演示、诠释、操作、安排、翻译。

**分析** - 在各种想法之间建立联系。区分、组织、关联、比较、对照、辨别、检查、实验、质疑、测试。

**评价** - 为立场或决定提供依据。评估、论证、辩护、判断、选择、支持、估价、评论、权衡。

**创造** - 产出新的或原创的作品。设计、组装、构建、推测、开发、拟定、撰写、调查。


## 知识类型

事实性知识

    * 术语知识
    * 具体细节和要素的知识

概念性知识

    * 分类和类别的知识
    * 原理和概括的知识
    * 理论、模型和结构的知识

程序性知识

    * 特定学科的技能和算法的知识
    * 特定学科的技术和方法的知识
    * 判断何时使用适当程序的标准的知识

元认知知识

    * 策略性知识
    * 关于认知任务的知识，包括适当的情境性和条件性知识
    * 自我认知
