# Model Dreyfus o gaffael sgiliau

https://en.wikipedia.org/wiki/Dreyfus_model_of_skill_acquisition

Mae model Dreyfus o gaffael sgiliau yn fodel o sut mae dysgwyr yn caffael sgiliau drwy addysgu ffurfiol ac ymarfer, a ddefnyddir ym meysydd addysg ac ymchwil gweithrediadau.

Mae'r model yn cynnig bod myfyriwr yn mynd drwy bum cam gwahanol:

* Newyddian (Novice)
* Cymhwysedd (Competence)
* Hyfedredd (Proficiency)
* Arbenigedd (Expertise)
* Meistrolaeth (Mastery)
