# 六西格玛成熟度模型

参见 https://www.isixsigma.com/implementation/basics/maturity-model-describes-stages-six-sigma-evolution/

五个级别：

<ul>

<li>1 级：启动。3-9 个月。


  <ul>
  <li>这是起点——组织中最初的少数有远见者启动六西格玛，开始培训并展开项目。</li>
  <li>关键挑战：确保执行六西格玛工作的初始团队在组织中得到必要的支持，并确保正确选择项目，以便在下一级别取得成功。</li>
  </ul>

<li>2 级：早期成功。6-18 个月。

  <ul>
  <li>最初的项目正在产生成果，并取得了早期成功。</li>
  <li>关键挑战：确保项目在合理的时间内完成，并对业务产生有意义的财务影响。</li>
  </ul>

<li>3 级：规模化与复制。12-36 个月。

  <ul>
  <li>早期的成功使组织的其他部门也认同六西格玛，更广泛的项目正在展开。</li>
  <li>关键挑战：确保方法论在公司其他部门得到一致应用，并确保财务影响和成果得以复制。</li>
  </ul>

<li>4 级：制度化。24-48+ 个月。

  <ul>
  <li>在公司的许多部门，项目正在产生广泛的财务影响。</li>
  <li>关键挑战：建立一致的六西格玛执行流程，同时允许公司不同部门存在可控的差异。</li>
  </ul>

<li>5 级：文化转型。48+ 个月。

  <ul>
  <li>六西格玛成为组织 DNA 的一部分，财务影响持续存在，六西格玛文化无处不在——甚至超出六西格玛从业者的范围，超越公司的边界。</li>
  <li>关键挑战：保持六西格玛的活力，并在公司不可避免地经历增长、威胁、收购等自然商业周期时，在可应用的新领域创新。</li>
  </ul>

</ul>

<th>战略成熟</th>

<td>-</td>

<td>-</td>

<td>地图、目标：创建战略地图，确保正在进行的大量项目与公司及组织的优先事项保持一致</td>

<td>项目汇总：公司和组织层面的战略地图；不止于一致，而是真正启动项目来影响战略目标</td>

<td>完整闭环：从战略到项目，再到项目成果汇总，直至组织战略目标的完整闭环</td>

<th>软件</th>

<td>-</td>

<td>Excel、统计：重点是面向黑带/绿带的统计工具</td>

<td>项目跟踪：软件超越统计工具，扩展到项目跟踪；确保方法论的一致应用和财务影响报告</td>

<td>组合管理：项目跟踪通常会演进为包含知识管理和组合管理</td>

<td>战略 + 组合：整个企业的集成组合与战略管理；用供应商应用取代遗留应用</td>

</tr>

<tr>

<th>报告</th>

<td>轶事性的</td>

<td>汇总、平均：尚无一致性，因项目数量仍少，无法汇总</td>

<td>汇总、平均：完成的项目足够多，可以预测每个项目、每位黑带等的平均影响；整个组织的汇总影响显著</td>

<td>跨组织比较：比较每个组织单元的结果；报告全公司范围的汇总结果</td>

<td>多年历史：例行比较每个组织单元的结果；报告全公司范围的汇总结果</td>

</tr>

<tr>

<th>财务影响</th>

<td>临时性：尚无，没有完成的项目</td>

<td>降低成本：初步成果产生了一些影响；通常聚焦于降低成本</td>

<td>一致性、EP：已有一致的影响度量</td>

<td>验证：已有严格的控制以确保成果的验证；度量方法演进为包含收入影响</td>

<td>总账：已有严格的控制以确保成果的验证；度量包含收入影响</td>

</tr>

<tr>

<th>项目选择</th>

<td>燃烧的平台：通常由燃烧的平台提供焦点；但需要避免“煮沸海洋”；需要管理过高的期望</td>

<td>低垂的果实：低垂的果实（容易识别且会产生显著成果的项目）很多</td>

<td>复制成功：通常是复制已经做过的成功模式（针对工厂/配送中心等类似问题的类似项目）</td>

<td>创意管道：已有正式的创意产生/评估流程，以确保有意义项目的持续涌现；没有更多低垂的果实</td>

<td>正式评估：已有正式的创意产生/评估流程，以确保有意义项目的持续涌现</td>

</tr>

<tr>

<th>人员</th>

<td>少数有干劲的人：少数有干劲的信徒，组织其余部分大多持怀疑态度</td>

<td>更多信徒：初步成果有所帮助；但组织的大部分仍在观望这是否会影响他们</td>

<td>职业发展：六西格玛现在被视为职业发展路径；整个组织的变革推动者看到了一个行之有效的平台</td>

<td>回归：第一批黑带已经回归，在组织中拥有更好的职业前景和职位</td>

<td>多数：第一批黑带已经回归，在组织中职业声望和职位都有所提升</td>

</tr>

<tr>

<th>培训</th>

<td>倡导者、高管：通过外部培训师获得高管支持；倡导者培训；确定并培训初始黑带</td>

<td>外部：已完成几批，通常仍由外部提供</td>

<td>外部、定制：整个公司开展多批培训；通常由外部培训师提供；内容根据公司定制</td>

<td>内部、电子学习：规模非常大；通常内部化，使用内部的黑带大师作为培训师；使用电子学习来实现规模化</td>

<td>内部、专长：规模非常大；通常内部化，使用内部的黑带大师作为培训师；使用电子学习来实现规模化</td>

</tr>

<tr>

<th>领导层支持</th>

<td>1 或 2 位有远见者：需要最初的有远见者提供采用的推动力——自上而下或自下而上</td>

<td>已验证：已完成的初始项目验证了领导层的愿景</td>

<td>全公司：决定在全公司推动六西格玛；整个公司的领导层都认同</td>

<td>被期待：整个业务单元、地区和部门的高层领导都被期望成为六西格玛的支持者</td>

<td>根深蒂固：整个业务单元、地区和部门的高层领导都被期望成为六西格玛的支持者</td>

</tr>
