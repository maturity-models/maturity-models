# 高德纳（Gartner）身份与访问管理计划成熟度模型

参见 [The Gartner IAM Program Maturity Model](https://image.slidesharecdn.com/thegartneriamprogrammaturitymodel-100125033123-phpapp02/95/the-gartner-iam-program-maturity-model-1-728.jpg)

<table>

<tr>
<th></th>
<th>1 级<br>初始</th>
<th>2 级<br>发展中</th>
<th>3 级<br>已定义</th>
<th>4 级<br>受管理</th>
<th>5 级<br>优化</th>
</tr>

<tr>
<th>治理</th>
<td>临时性、非正式</td>
<td>并入信息安全（及其治理结构）</td>
<td>IAM 治理结构已定义并获认可</td>
<td>IAM 治理结构已落实并完善</td>
<td>IAM 治理优化</td>
</tr>

<tr>
<th>组织</th>
<td>非正式、基本角色、职责分散</td>
<td>技术项目由业务单元和首席信息安全官赞助；非正式的 IAM 技能清单</td>
<td>IAM 项目管理计划（PMP）已建立；IAM 角色和培训已定义</td>
<td>IAM 项目管理办公室（PMO）已运作；RACI 矩阵已定义；主动的技能发展</td>
<td>与业务实现最佳整合；技能已优化</td>
</tr>

<tr>
<th>愿景与战略</th>
<td>至多停留在概念认知</td>
<td>已识别某些业务驱动因素；已确定战术优先事项</td>
<td>与业务对齐的愿景已定义；战略优先事项已确定</td>
<td>IAM 愿景和战略持续审查，以跟踪业务战略</td>
<td>定期优化愿景和战略</td>
</tr>

<tr>
<th>流程</th>
<td>临时性、非正式</td>
<td>半正式的、针对特定业务单元和特定目标的流程</td>
<td>正式流程已定义，在各业务单元和目标系统之间保持一致</td>
<td>正式流程已整合并完善，与业务流程保持一致</td>
<td>流程优化</td>
</tr>

<tr>
<th>架构与基础设施设计</th>
<td>可能使用针对特定目标的生产力工具</td>
<td>互不关联的技术项目；很可能存在技术冗余</td>
<td>独立的 IAM 架构已定义；合理化与整合正在进行</td>
<td>IAM 架构已完善并与企业架构（EA）对齐</td>
<td>IAM 架构嵌入企业架构；优化</td>
</tr>

<tr>
<th>业务价值</th>
<td>无可衡量的价值</td>
<td>战术性的效率（也许还有效果）提升；直接价值低</td>
<td>持续、可量化的改进，与治理、风险和合规（GRC）要求挂钩；直接价值中等</td>
<td>对所有关键业务要求做出持续、可量化的贡献；直接价值高</td>
<td>业务价值优化；变革性的直接价值</td>
</tr>

</table>
