# Prowareness 技能成熟度模型

参见 [Prowareness Team Maturity Model](http://agilityladder.nl/files/2015/06/Prowareness-Team-Maturity-Model_presentation.pdf)

<tr>
<th>知识</th>
<td>知识极少，或仅有未与实践联系起来的“教科书”知识</td>
<td>掌握实践关键方面的工作知识</td>
<td>对实践领域有良好的工作知识和背景知识</td>
<td>对学科和实践领域有深入的理解</td>
<td>具有学科的权威知识，并对整个实践领域有深刻的隐性理解</td>
</tr>

<tr>
<th>工作标准</th>
<td>除非受到密切监督，否则不太可能令人满意</td>
<td>简单任务很可能达到可接受的标准</td>
<td>适合预期用途，但可能缺乏精细打磨</td>
<td>例行地达到完全可接受的标准</td>
<td>相对轻松地达到卓越</td>
</tr>

<tr>
<th>自主性</th>
<td>需要密切的监督或指导</td>
<td>能凭自己的判断完成一些步骤，但整体任务仍需监督</td>
<td>能凭自己的判断完成大多数任务</td>
<td>能为自己的工作（以及在适用时为他人的工作）承担全部责任</td>
<td>能承担超越现有标准并创造自己诠释的责任</td>
</tr>

<tr>
<th>应对复杂性</th>
<td>几乎没有或完全没有应对复杂性的概念</td>
<td>理解复杂情况，但只能实现部分解决</td>
<td>通过有意识的分析和规划来应对复杂情况</td>
<td>以整体方式处理复杂情况，决策更有信心</td>
<td>整体把握复杂情况，轻松地在直觉与分析方法之间切换</td>
</tr>

<tr>
<th>对情境的感知</th>
<td>倾向于孤立地看待行动</td>
<td>将行动视为一系列步骤</td>
<td>至少部分地从长期目标的角度看待行动</td>
<td>看到整体“图景”以及各项行动如何融入其中</td>
<td>看到整体“图景”和替代方法；对可能性有远见</td>
</tr>

</table>
