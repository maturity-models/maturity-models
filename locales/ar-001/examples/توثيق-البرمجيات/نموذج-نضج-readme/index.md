# نموذج نضج README

## المستوى الأول: «الشيفرة هي التوثيق»

- لا نص README من أي نوع، أو يكاد لا يوجد.
- لا تفاصيل عن التثبيت والتهيئة والتشغيل.
- لا توثيق للمطورين.
- لا ملفات مكمّلة، مثل إرشادات المساهمين.
- لا معلومات عن حالة البناء، فلا نظرة على الحالة الراهنة للمشروع.
- لا زمن استجابة متوسط مقترح للقضايا و/أو طلبات السحب.
- لا شارات تُظهر تغطية الشيفرة أو مقاييس الجودة الأخرى.
- قد يكون النص المتوفر قديمًا أو غير ذي أولوية.

**التوصية**: ينشر المطورون أحيانًا مشاريع شخصية وتجارب غير جاهزة للمشاركة. وفي هذه الحالات، قد يكون التوثيق القليل أو المعدوم مقبولًا. نوصي بأن يبيّن README طبيعة المشروع/حالته. على سبيل المثال، حذّر المستخدمين من أن «هذا المشروع تجريبي/شخصي، فاستخدمه على مسؤوليتك».

## المستوى الثاني: README الحد الأدنى

- معلومات محدودة عن وظيفة المشروع وغرضه.
- تفاصيل أساسية للمستخدمين عن التثبيت والتهيئة والتشغيل، لكنها غير مختبرة وغير كاملة.
- توثيق أساسي للمطورين أو لا توثيق.
- سطر في README عن المساهمات، لكن دون ملف مخصص.
- سطر عن حالة بناء المشروع، وإن كان قد يكون قديمًا؛ أو لا معلومات عن حالة البناء.
- سطر عن زمن الاستجابة المتوسط للقضايا و/أو طلبات السحب.
- لا شارات تُظهر تغطية الشيفرة أو مقاييس الجودة الأخرى.
- النص نادرًا ما يُحدَّث وقد يكون قديمًا أو غير دقيق.

**التوصية**: يستهدف README المستوى الثاني جمهورًا واسعًا، لكن عدم اكتماله يسبب الإحباط وجهدًا ضائعًا. وأحيانًا يكون هذا أسوأ من انعدام التوثيق تمامًا. أدرج ملاحظة تبيّن ما إذا كان المشروع في مرحلة مبكرة أو غير مستقر أو تجريبيًا أو شخصيًا.

## المستوى الثالث: README أساسي

- بعض المعلومات التفصيلية عن وظيفة المشروع وفائدته وغرضه.
- تفاصيل أساسية للمستخدمين عن التثبيت والتهيئة والتشغيل، مختبرة وكاملة.
- توثيق أساسي للمساهمين المحتملين.
- بيان رؤية أو خارطة طريق للمشروع لاستقطاب المساهمين الجدد.
- ملف Contributing.md/.rst بمعلومات أساسية.
- سطر عن حالة بناء المشروع، لكنه مقتضب: «قيد التطوير» أو «مستقر».
- سطر عن زمن الاستجابة المتوسط للقضايا و/أو طلبات السحب.
- شارة واحدة على الأقل تُظهر تغطية الشيفرة أو مقاييس الجودة الأخرى.
- يُحدَّث النص كل شهر أو كل ربع سنة، فقد توجد أخطاء.

**التوصية**: README المستوى الثالث شامل بما يكفي لدعم نمو مجتمعي صغير النطاق. وينبغي للمشاريع المبكرة التي تحتاج إلى استقطاب مساهمين أن تسعى إلى بلوغ هذا المستوى قبل النشر. ويمكن أن يحدث تبنٍّ واسع للمشروع، رغم أن README قد يشكّل عوائق.

## المستوى الرابع: README ذو غرض

- معلومات تفصيلية عن غرض المشروع ووظيفته وميزاته/سماته الخاصة.
- تعليمات تفصيلية للمستخدم عن التثبيت والتهيئة والتشغيل قد تكون حُدّثت حديثًا أو لا؛ ومعلومات عن الأخطاء الشائعة وكيفية حلها.
- توثيق تفصيلي للمساهمين المحتملين.
- بيان رؤية تفصيلي أو خارطة طريق للمشروع لاستقطاب المساهمين الجدد.
- ملف Contributing.md/.rst بإرشادات أسلوب تفصيلية.
- تحدد حالة البناء جوانب محددة من المشروع غير مكتملة و/أو تسبب عدم الاستقرار.
- معلومات واضحة عن زمن الاستجابة المتوسط للقضايا و/أو طلبات السحب.
- شارة أو أكثر تُظهر تغطية الشيفرة أو مقاييس الجودة الأخرى.
- يُحدَّث النص كل شهر أو كل ربع سنة، فقد توجد أخطاء.

**التوصية**: يمكن لـ README المستوى الرابع دعم الاستخدام والنمو المجتمعي واسعي النطاق. وقد يفتقر إلى بعض المكونات الضرورية لتحقيق استخدام وتبنٍّ واسعين. وقد تتردد الشركات التي تفرض معايير صارمة للتبني قبل استخدامه.

## المستوى الخامس: README موجَّه نحو المنتج

- معلومات تفصيلية عن غرض المشروع ووظيفته وميزاته/سماته الخاصة، بحيث يستطيع القارئ فهم فائدة ميزاته وسماته وأثرها فورًا.
- شهادات المستخدمين ودليل على الأداء السابق في مواقف تطوير حقيقية.
- تعليمات تفصيلية للمستخدم عن التثبيت والتهيئة والتشغيل، مختبرة وحديثة؛ ومعلومات عن الأخطاء الشائعة وكيفية حلها.
- توثيق تفصيلي للمساهمين المحتملين.
- بيان رؤية تفصيلي أو خارطة طريق للمشروع لاستقطاب المساهمين الجدد.
- وسائل إيضاح بصرية مضمنة مثل المخططات والعروض التوضيحية.
- ملف Contributing.md/.rst بإرشادات أسلوب تفصيلية.
- تحدد حالة البناء جوانب محددة من المشروع غير مكتملة و/أو تسبب عدم الاستقرار.
- معلومات واضحة عن زمن الاستجابة المتوسط للقضايا و/أو طلبات السحب.
- شارة أو أكثر تُظهر تغطية الشيفرة أو مقاييس الجودة الأخرى.
- يُحدَّث النص كل أسبوع أو حتى كل يوم، فاحتمال وجود أخطاء ضعيف.

**التوصية**: عادةً ما تنبثق ملفات README المستوى الخامس من مشاريع ذات قاعدة واسعة من المساهمين/المستخدمين. ويعزز تفصيلها الاستخدام الجاهز للإنتاج والمساهمات الخاضعة للإشراف. ينبغي لكل مشروع أن يطمح إلى هذا المستوى من التوثيق.
