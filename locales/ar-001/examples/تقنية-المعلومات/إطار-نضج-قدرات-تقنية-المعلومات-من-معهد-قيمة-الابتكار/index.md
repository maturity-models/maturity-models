<h2><a name="إدارة-تقنية-المعلومات-كأعمال">إدارة تقنية المعلومات كأعمال</a></h2>

1. ابتدائي - غير مُدار

  * لا توجد استراتيجية لتقنية المعلومات

  * لا توجد عمليات محددة لتقنية المعلومات

2. أساسي - مركز تكلفة - تقنية المعلومات مركز تكلفة

  * أنظمة الأصول ومراكز التكلفة قائمة

  * تقنية المعلومات تركّز حصرًا على التقنية والعملية

  * وُثّقت بعض عمليات تقنية المعلومات

3. متوسط - مركز خدمة - تقنية المعلومات موجَّهة للعملاء والخدمة

  * أنظمة استرداد التكاليف ومحاسبة التكاليف قائمة

  * تُنفَّذ ممارسات تسليم الخدمات وإدارتها

4. متقدم - مركز استثمار - تقنية المعلومات تركّز على تميز الخدمة والاستخدام

  * إدارة علاقات عملاء تقنية المعلومات وموردينها ممتازة

  * آليات التمويل مرنة

  * تستخدم تقنية المعلومات تخصيص الموارد الديناميكي

5. تحسين - مركز قيمة - تقنية المعلومات مركز قيمة وتنشر بيانات القيمة بانتظام

  * قيم تقنية المعلومات والأعمال متوائمة بدرجة عالية

  * تستخدم مؤسسة تقنية المعلومات بطاقات الأداء المتوازن لدفع التحسين المستمر

  * مؤسسة تقنية المعلومات ريادية بقوة


<h2><a name="إدارة-ميزانية-تقنية-المعلومات">إدارة ميزانية تقنية المعلومات</a></h2>

1. ابتدائي - غير مُدار - الأداء المالي متقلب

  * ليس لميزانية تقنية المعلومات مالك واضح

  * إنفاق تقنية المعلومات غير مرئي ومجزأ

  * تمويل تقنية المعلومات غير متوائم مع قيمة الأعمال طويلة الأمد

2. أساسي - أداء مالي يمكن التنبؤ به

  * توجد ميزانية محددة لتقنية المعلومات

  * تتتبع تقنية المعلومات الأداء مقابل الخطط المالية وخطط الإنفاق الدورية

  * يبقى التباين بين الإنفاق الفعلي والمخطط ضمن حد تحكم محدد

3. متوسط - خفض منهجي للتكاليف - عمليات خفض التكاليف المنهجي قائمة

  * تُتتبع اتجاهات تكاليف وحدة تقنية المعلومات وتُخفَّض سنويًا

  * نهج ميزانية أساسية ديناميكية لتقنية المعلومات قائم

4. متقدم - خيارات تمويل موسّعة - جذبت تقنية المعلومات مصادر تمويل متعددة

  * تُحوَّل وفورات التكاليف إلى استثمارات استراتيجية أو إلى الربح

  * ميزانية تقنية المعلومات ممتثلة للحوكمة ولمبادئ استخدام تقنية المعلومات

  * ميزانية تقنية المعلومات متوائمة مع قيمة الأعمال طويلة الأمد

5. تحسين - تضخيم الميزانية - ميزانية مستقرة لتقنية المعلومات تدعم متطلبات نمو الشركة

  * توزَّع مخصصات الميزانية بتوازن عبر محافظ مناسبة قائمة على أداء القيمة

  * تُدار كثافة تقنية المعلومات بنشاط وتُقارن بفئات الإنفاق المؤسسي الرئيسية الأخرى

  * تُقاد الميزانية بخرائط طريق المؤسسة والأعمال طويلة الأمد


<h2><a name="إدارة-قدرة-تقنية-المعلومات">إدارة قدرة تقنية المعلومات</a></h2>

1. ابتدائي - غير مُدار - المستخدمون يشترون أنظمة تقنية المعلومات ويصونونها

  * لا حضور رسمي لتقنية المعلومات

  * لا تكامل بين أنظمة تقنية المعلومات

2. أساسي - مرفق عام أو مورّد تقنية

  * احترام متنامٍ لمؤسسة تقنية المعلومات

  * ترى الشركة تقنية المعلومات بوصفها مركز تكلفة بحتًا

  * تقنية المعلومات تكلفة يجب خفضها باستمرار

3. متوسط - خبير تقني - لتقنية المعلومات سجل في تقديم خدمات جيدة وموثوقة

  * تُقصد مؤسسة تقنية المعلومات كمصدر للخبرة التقنية

  * توفر تقنية المعلومات خدمة مرفق موثوقة تُقارَن على أساس الأداء والتكلفة

4. متقدم - شريك أعمال استراتيجي - قيادة تقنية المعلومات متكاملة مع قيادة الأعمال

  * تقدم تقنية المعلومات حلولًا توفر قيمة في مجالات أعمال محددة

  * توفر تقنية المعلومات قدرات تنافسية رئيسية في مجالات مستهدفة

  * يفهم قادة تقنية المعلومات الأعمال ويقترحون استباقيًا حلولًا للفرص والمشكلات الرئيسية

5. تحسين - كفاءة جوهرية استراتيجية - تمكّن تقنية المعلومات تفوق المعلومات و/أو التنفيذ على المنافسة

  * يوفر تدفق مستمر من الحلول ميزة تنافسية

  * تُعرف تقنية المعلومات بوصفها كفاءة جوهرية مميِّزة


<h2><a name="إدارة-تقنية-المعلومات-لتحقيق-قيمة-الأعمال">إدارة تقنية المعلومات لتحقيق قيمة الأعمال</a></h2>

1. ابتدائي - غير مُدار - القرارات مبنية على التكلفة لا القيمة

  * لا فهم ولا قياس للقيمة التي توفرها تقنية المعلومات

  * إجمالي تكلفة الملكية يتصاعد بشكل جامح

2. أساسي - إجمالي تكلفة الملكية - تحتسب تقنية المعلومات إجمالي تكلفة الملكية للأصول الرئيسية

  * تتتبع تقنية المعلومات إجمالي تكلفة الملكية بانتظام لضمان الخفض المستمر للتكاليف

  * تحتسب تقنية المعلومات إجمالي تكلفة الملكية لدورة الحياة الكاملة

3. متوسط - العائد البسيط على الاستثمار وانضباط دراسة الجدوى

  * استخدام ومراجعة منضبطان لدراسات الجدوى

  * لدى تقنية المعلومات إما حوكمة استثمار أو برنامج لقيمة الأعمال

  * تستخدم تقنية المعلومات تحليلًا متعدد المقاييس لدراسات الجدوى لتحديد الاستثمارات الأعلى جودة

4. متقدم - إدارة المحفظة والخيارات

  * لدى تقنية المعلومات برنامج استباقي لإدارة المحفظة

  * تستخدم تقنية المعلومات نهج إدارة الخيارات لاختيار الاستثمارات المضاربية في تقنية المعلومات وإدارتها

  * تزن تقنية المعلومات المخاطر والقيمة المعرَّضة للخطر كمكونات رئيسية لدراسات الجدوى

5. تحسين - عائد استثمار مُحسَّن

  * تجري تقنية المعلومات تحليلًا متطورًا للاستثمار والمحفظة لتحسين الاستثمارات والإنفاق

  * عوائد الاستثمارات المدعومة بتقنية المعلومات مساوية لعوائد أنواع الاستثمار الأخرى في الشركة أو أكبر منها

  * تتيح البيانات التاريخية تنبؤات دقيقة بقيمة الاستثمارات المستقبلية
